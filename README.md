# StoryForge · AI 短剧工坊

一个从剧本输入开始，按步骤管理短剧生产流程的 Windows 本地 PC 应用。

## 安装 PC 版

打包完成后，在 `release-v0.10.0` 文件夹中使用：

- `StoryForge-Setup-0.10.0-x64.exe`：Windows 安装程序。

安装时可以选择安装位置，并创建桌面快捷方式。

## 生成 PC 安装包

```bash
npm install
npm run desktop:pack
```

生成文件保存在 `release-v0.10.0` 文件夹。

## 本地启动

```bash
npm install
npm run dev
```

打开终端输出的本地网址即可使用。

## 发布到公网（适合公司电脑 + 家里电脑）

不要让家里电脑访问公司电脑的 `localhost`，也不要依赖公司局域网 IP。项目已经包含 Vercel 和 Netlify 的静态部署配置：

1. 将整个项目上传到 GitHub。
2. 在 Vercel 或 Netlify 中导入该仓库。
3. 构建命令使用 `npm run build`，发布目录使用 `dist`。
4. 发布后得到一个所有电脑都能访问的网址。

也可以在安装并登录 Vercel CLI 后运行：

```bash
npx vercel
```

发布后，公司电脑和家里电脑都访问同一个 `https://...` 网址，不要求两台电脑在同一网络，也不要求公司电脑一直开机。

## 当前能力

- 粘贴剧本或导入 TXT / Markdown 文件
- 一键载入示例剧本
- 按故事分析、分集大纲、短剧剧本、分镜脚本、视觉素材、视频生成推进
- 每一步展示生成状态、结果预览、重新生成和进入下一步
- 浏览器本地自动保存项目状态（当前每台电脑各自保存一份）
- 复制当前结果、导出 JSON 项目包
- 导入 JSON 项目包，可在另一台电脑继续工作
- 按 Seedance 2.0 Skill 生成逐镜头提示词，并根据剧情为每镜动态分配时长
- 自动分配 `@Image`、`@Video`、`@Audio` 的引用用途并检查素材限制
- 支持复制单镜头或全部 Seedance 提示词
- 故事分析到分镜脚本由 DeepSeek 自动连续生成，无需逐步确认
- 第五步暂时关闭 Seedream 5.0 与 GPT Image 2 模型生图，统一改为上传本地参考图片
- 为每个人物、场景、群像和道具分别提供独立上传入口，可为同一项追加多张参考图
- 上传图片自动复制到“文档/StoryForge/项目名称/项目编号/视觉素材/本地上传”目录
- 支持预览、在资源管理器中定位、清空单项关联，并在重启软件后继续使用
- 所有必需素材上传完成后，手动确认并进入第六步
- 第六步接入火山方舟 Seedance 2.0 和 Seedance 2.0 Fast，按分镜逐条创建真实视频任务
- 根据每个镜头的素材名称自动匹配 `@ImageN` 与第五步本地参考图，并以 Base64 参考素材提交给 Seedance
- 支持 9:16、16:9 等比例、480p / 720p、4 至 15 秒和同步音频开关
- 第六步优先读取每个分镜的结构化时长，旧项目可从“生成九秒”或“0-12 秒”类提示词自动恢复秒数
- 视频设置中的镜头时长为“按分镜自动”，不再显示容易被误解为统一时长的秒数下拉框
- 第六步同时提供“生成下一个镜头”和“批量生成全部视频”按钮，每张镜头卡也可单独生成或重试
- 视频任务支持排队、生成、下载、完成和失败状态，失败镜头可单独重试
- 生成视频自动保存到“文档/StoryForge/项目名称/项目编号/视频片段”目录
- Seedance API Key 使用 Windows 本机加密保存
- 明确显示模型未开通、Key 无效、额度不足、请求超时等真实接口错误
- 已移除九宫格制作参考板，不再生成或展示九宫格图片任务
- 自动流程在视频生成前停止，视频必须手动点击开始
- 使用 Codex 风格的 Windows 系统字体与清晰字号
- 支持 `Ctrl +`、`Ctrl -` 和 `Ctrl 0` 调整界面缩放
- 从人物表和对白中识别真实人物姓名，排除标题、类型、规格等元数据
- 除即梦平台要求的素材引用标记外，分镜提示词全部使用中文
- 视频生成前四个文本阶段调用 DeepSeek V4 Pro，不再使用本地模板
- DeepSeek API Key 使用 Windows 本机加密保存
- DeepSeek 返回内容经过人物、场次、分镜完整性和中英文混排校验

视频生成前四个文本阶段由 DeepSeek V4 Pro 完成，第五步按人物、场景、群像和道具上传本地参考图，第六步由火山方舟 Seedance 2.0 逐镜或批量生成视频。接口失败时会显示真实错误，不会退回本地演示模板。
