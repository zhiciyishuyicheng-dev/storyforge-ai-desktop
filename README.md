# StoryForge · AI 短剧工坊 1.0

将小说或剧本变成分镜、参考图和短剧视频的 Windows 本地应用。支持逐步创作，也支持从第一步自动完成全部镜头视频。

## 安装 1.0 正式版

从 [GitHub Releases v1.0](https://github.com/zhiciyishuyicheng-dev/storyforge-ai-desktop/releases/tag/v1.0) 下载 **StoryForge-Setup-1.0-x64.exe**，适用于 Windows 64 位系统。安装时可选择安装位置并创建桌面快捷方式，使用安装版无需自行安装 Node.js。

本地构建产物位于 `release-v1.0/StoryForge-Setup-1.0-x64.exe`。生成时需使用你自己的模型账号和额度，配置方式见下文。

## 当前能力

- 四步创作：故事分析 → 分镜脚本 → 视觉素材 → 视频生成，直接处理原始输入。
- DeepSeek V4.1 Flash 生成故事分析、分镜和素材提示词；支持内置 Skill v2.1 或本地上传的分镜规范。
- 分镜、资产分别上传 Skill，支持 TXT、MD、DOCX 和文字型 PDF，随项目保存并支持预览、替换及移除。
- GPT 订阅生图与本地图片上传；人物、场景、群像及道具按准确名称管理，重新生成追加图片版本。
- 分镜使用 `@准确素材名`，视频只绑定当前镜头实际引用的同名图片，兼容旧项目与已有选图。
- Seedance 2.0 / 2.0 Fast 支持单镜、逐镜或批量生成，按分镜时长保存独立 MP4，可编辑提示词、选择图片版本及重试失败镜头。
- 可选“一键跑完全流程”，自动衔接分镜、参考图和批量视频；阶段内的重新生成始终只执行对应阶段。
- 结果区全宽阅读，底部耗时详情可展开；生成中可浏览、复制同项目其他步骤，后台继续执行并保留阅读位置。
- 本机自动保存、多项目管理和 JSON 导入导出；模型密钥在 Windows 本机加密保存。

## 首次配置

| 用途 | 模型或能力 | 需要准备 |
| --- | --- | --- |
| 故事分析、分镜和素材提示词 | DeepSeek V4.1 Flash（`deepseek-flash`） | DeepSeek API Key |
| 第三步参考图 | GPT Image 2（`gpt-image-2`） | 本机官方 Codex，使用可用的 ChatGPT 账号登录 |
| 第四步视频 | Seedance 2.0 / 2.0 Fast | 火山方舟 API Key，以及已开通的对应视频模型 |

在软件设置中保存 DeepSeek 和 Seedance 配置。GPT 订阅生图通过本机 Codex 使用登录账号的订阅额度，无需填写 OpenAI API Key；在“GPT 订阅设置”中重新检测，自动查找失败时可手动选择 `codex.exe`。可用权限和额度以账号及实际请求结果为准。本地图片上传可独立使用，原有 Seedream / OpenAI 付费 API 生图入口保持关闭。

## 四步使用

1. **故事分析**：粘贴小说或剧本，或导入 TXT / MD；按需上传分镜 Skill，再开始生成。
2. **分镜脚本**：查看逐块提示词、时长及独立审计记录，可复制单块或全部正式正文。
3. **视觉素材**：按人物、场景、群像和道具生成或上传参考图，也可添加遗漏资源。所有素材有图后自动标记第三步完成，可直接进入第四步。
4. **视频生成**：检查当前镜头的具名素材绑定和图片版本，按需编辑提示词，生成单镜或批量生成全部视频。

图片按准确素材名保存，例如 `周成海.png`；重新生成追加版本。分镜使用 `@周成海`、`@办公室`、`@信纸` 等名称，用户无需维护图片序号。第四步只提交正文实际引用的图片，每镜最多 9 张；未知名称、同名歧义或错绑会明确阻止提交。旧编号项目和旧磁盘文件继续兼容，已有图片与成片保留。

## 上传本地 Skill

故事分析或分镜页面上传“分镜 Skill”，视觉素材页面上传“资产 Skill”。文档可指定时长、镜数、画风、模板和素材要求；支持 TXT、MD、DOCX、文字型 PDF，单文件最多 10 MiB、正文最多 200,000 字符，超限会提示，扫描 PDF 需先识别文字。

- 分镜 Skill 替换内置创作默认要求，生成、独立审核和一次回炉使用同一份文档；应用必需的数据结构和素材身份仍会校验。
- 资产 Skill 作用于素材提示词和下一次实际 GPT 生图。已有分镜后再上传，也可直接用于下一次生图。
- Skill 正文随项目保存和 JSON 导入导出。替换仅影响后续请求，历史成果保留当次依据，已有图文和视频不会自动重做。

未上传分镜 Skill 时使用完整的内置 v2.1，原文保存在 `electron/skills/storyboard-v2.1.txt`。生成后执行本地校验和独立审核，失败最多回炉 **一次**；再次审计失败但结构可用且没有真实剧情阻塞时，保留“审计未通过（已忽略）”警告并继续。截断、结构缺失、没有正式提示词或真实缺少剧情材料时仍暂停，并保留此前成果。内置规则执行 60 项审计，用户 Skill 按上传文档的实际条款审核。

分镜正文与审计附件分开展示，复制正文不混入审计说明。审计针对文本与计划，不能代替成片和配音的实际检查。应用已取消原先固定的 24,000 tokens 输出上限，模型与服务端自身的限制仍有效，单次请求保留 5 分钟总超时。

## 一键跑完全流程

打开左侧 **“一键跑完全流程”**，再点击 **“一键生成到视频”**：从第一步生成分析和分镜，补齐参考图，再批量生成并保存全部镜头视频。开关默认关闭，按项目保存。

- 开始前配置 DeepSeek、可用的 GPT 订阅生图和 Seedance；两个阶段的 Skill 使用本次启动锁定的文档。
- 自动模式按视频接口要求生成 **4–15 秒整数分块**，不会静默拉长短块或截断长块。逐步创作仍可保留内置规范允许的 1–3 秒自然短块，但提交视频前需合理重分块。
- 自动视频始终使用批量方式，全局“逐镜确认”设置保持原值；每镜保存独立 MP4。
- 可停止后续生成；遇到真实材料阻塞、生图失败或视频失败时暂停，保留已完成成果。真人素材需在方舟完成认证并绑定 Asset ID 后继续剩余任务；重启后不会自动重复提交。

## 生成中浏览与阶段重试

同一项目生成时，可点击四个步骤查看和复制已有结果。只有实际运行的步骤显示转圈和“生成中”，提示条提供“返回生成页面”和“停止当前任务”。后台刷新保留阅读位置，用户主动切换后不会被阶段完成或自动接力强制切回。原文、提示词及素材修改在运行期间锁定；切换到另一个项目仍会停止当前本地任务。

阶段按钮的作用始终明确，不受全流程开关影响：

- **重新生成参考图**：按当前素材提示词追加图片版本，保留分析、分镜、原图和已有视频。
- **重新生成全部视频**：仅重做视频。
- **重新生成分析与分镜**：前两步共用的生成入口。

全流程只从左侧“一键生成到视频”主动启动。关闭全流程后，第三步左侧按钮仅补齐缺图，第四步入口仅生成视频。

## 本机数据与网页模式

图片和视频保存在 Windows“文档/StoryForge/项目标题/项目编号”下，按视觉素材、视频片段等目录分类。JSON 项目包用于备份和迁移项目文本、Skill 与关联信息；本地媒体文件需另行备份。各电脑的数据独立保存，当前没有账号登录、云端数据库或自动跨电脑同步。

完整生成能力面向 Electron 桌面版。`npm run dev` 或 Vercel / Netlify 静态部署可用于网页界面预览和本地文字项目管理；纯网页没有桌面通信桥，不能连接本机 Codex，也不提供完整的模型调用、原生文档解析、本机密钥加密和媒体落盘流程。将前端发布到公网不会自动获得这些桌面能力。

## 开发与打包

源码开发环境需要 Node.js 22.13+（或 24+）和 npm，依赖版本以 `package-lock.json` 为准。

```bash
npm ci
npm run dev          # 网页界面开发
npm run desktop      # 构建并运行桌面版
npm run desktop:pack # 生成 Windows 安装包
npm test             # 运行离线测试
```

打包输出：`release-v1.0/StoryForge-Setup-1.0-x64.exe`。关键架构、生成边界和维护要求见 [源码交接说明](HANDOFF.zh-CN.md)。
