# XStudio 1.1.1

将小说或剧本变成分镜、参考图和短剧视频的 Windows 本地应用。支持逐步创作，也支持从第一步自动完成全部镜头视频。

## 安装与更新

当前版本为 **1.1.1 预览版**，软件更名为 XStudio，程序、安装包、快捷方式和窗口使用统一名称，并采用用户提供的透明背景黑色图标。包含仙宫云 ComfyUI H3 视频接入；真实 GPU 出片仍待验证。

本次修复版安装包为 `XStudio-Setup-1.1.1-x64.exe`，发布完成后可在 [GitHub Releases](https://github.com/zhiciyishuyicheng-dev/storyforge-ai-desktop/releases/tag/v1.1.1) 下载。

关闭旧软件后安装更新，可选择安装位置并创建桌面快捷方式，使用安装版无需自行安装 Node.js。改名沿用旧版应用标识与数据目录，保留已有项目、模型设置及 H3 任务记录。已有项目默认保留 DeepSeek 生成方式，可在前两步切换为 GPT 订阅。生成时需使用自己的模型账号和额度，配置方式见下文。

## 当前能力

- 四步创作：分镜大纲 → 分镜脚本 → 视觉素材 → 视频生成。普通模式只生成当前步骤，完成后停留原页，用户确认后才启动下一步；只有“一键跑完全流程”会自动接力。
- 前两步可选 DeepSeek V4.1 Flash 或 GPT 订阅生成分镜大纲、分镜和素材提示词；支持内置 Skill v2.1 或本地上传的分镜规范。
- GPT 模型和思考强度按本机 Codex 提供的选项动态读取，按项目保存；生成、审计和回炉锁定同一次选择。
- 分镜、资产分别上传 Skill，支持 TXT、MD、DOCX 和文字型 PDF，随项目保存并支持预览、替换及移除；可从历史记录中预览并复用之前的同类 Skill。
- GPT 订阅生图与本地图片上传；人物、场景、群像及道具按准确名称管理，重新生成追加图片版本。
- 分镜使用 `@准确素材名`，视频只绑定当前镜头实际引用的同名图片，兼容旧项目与已有选图。
- 仙宫云 H3 Ref2VA：粘贴实例 ComfyUI 地址并测试连接，自动检测模型，按精确素材名映射图片参考。详见[仙宫云接入说明](docs/XIANGONG-H3.zh-CN.md)。
- Seedance 2.0 / 2.0 Fast 支持单镜、逐镜或批量生成，按分镜时长保存独立 MP4，可编辑提示词、选择图片版本及重试失败镜头。
- 第四步底部显示 1～N 分镜导航，完成显示 √，生成中转圈；点击编号定位镜头，每镜支持重新生成、历史版本切换及查看所选版本文件。
- 每段视频播放器位于该段顶部，横向铺满输出区，提示词和素材绑定位于下方；横屏或竖屏内容均保持原画比例。
- 更换被拦截的参考图后清理对应旧认证记录，可直接重新提交当前选图；为被拦截素材追加新图时自动切换对应引用，旧图仍保留。
- 可选“一键跑完全流程”，自动衔接分镜、参考图和批量视频；阶段内的重新生成始终只执行对应阶段。
- 结果区全宽阅读，底部耗时详情可展开；生成中可浏览、复制同项目其他步骤，后台继续执行并保留阅读位置。
- 本机自动保存、多项目管理和 JSON 导入导出；模型密钥在 Windows 本机加密保存。

## 首次配置

| 用途 | 模型或能力 | 需要准备 |
| --- | --- | --- |
| 分镜大纲、分镜和素材提示词 | DeepSeek V4.1 Flash（`deepseek-flash`） | DeepSeek API Key |
| 分镜大纲、分镜和素材提示词（另一种方式） | GPT 订阅，模型及思考强度可选 | 本机官方 Codex，使用 ChatGPT 账号登录 |
| 第三步参考图 | GPT Image 2（`gpt-image-2`） | 本机官方 Codex，使用可用的 ChatGPT 账号登录 |
| 第四步视频 | Seedance 2.0 / 2.0 Fast | 火山方舟 API Key，以及已开通的对应视频模型 |

选择 DeepSeek 时，在设置中保存 DeepSeek API Key；选择 GPT 订阅时，在前两步的“生成方式”中切换，点击“订阅设置 / 检测”，再选择模型和思考强度，无需 DeepSeek 或 OpenAI API Key。分镜和生图共用本机 Codex 登录及程序路径，但分别检查文本和生图能力，不能生图的账号不会因此被禁止生成文本分镜。自动查找失败时可手动选择 `codex.exe`。视频仍需配置 Seedance。

GPT 订阅通过 [官方 Codex app-server](https://learn.chatgpt.com/docs/app-server) 使用 ChatGPT 登录。模型目录用于选择，具体可用权限和额度以实际请求结果为准；额度或权限错误会显示并保留已有成果，不会切换到付费 API。本地图片上传可独立使用，原有 Seedream / OpenAI 付费 API 生图入口保持关闭。

## 四步使用

1. **分镜大纲**：输入剧本、选择模型和分镜 Skill 后，仅生成“生成块 / 预计时长 / 场景 / 剧情内容与镜头重点”表格，停留第一步。确认后点击“确认大纲，生成分镜脚本”。
2. **分镜脚本**：按已确认大纲生成逐块提示词和审计记录，不提前生成资产提示词。完成后停留第二步，点击“确认分镜，生成资产提示词”才继续。
3. **视觉素材**：先生成资产提示词并等待确认；用户再点击生成参考图或上传图片。已有图片仍保留，全部齐备后点击进入第四步。可单独重新生成资产提示词。
4. **视频生成**：检查具名素材绑定及提示词，生成单镜或批量生成全部视频；通过底部编号定位镜头，使用“第 N 版”按钮切换历史成片。

图片按准确素材名保存，例如 `周成海.png`；重新生成追加版本。分镜使用 `@周成海`、`@办公室`、`@信纸` 等名称，用户无需维护图片序号。第四步只提交正文实际引用的图片，每镜最多 9 张；未知名称、同名歧义或错绑会明确阻止提交。旧编号项目和旧磁盘文件继续兼容，已有图片与成片保留。

参考图被平台拦截后，可以在第三步重新上传，或在第四步切换为同一素材的新图片，再点击“重新生成此镜头”。旧认证记录不会直接阻止新请求；只有平台对本次提交再次返回真人素材拦截时，才重新显示对应认证要求。需要继续使用原图时，仍可选择“完成认证并继续”。

## 视频分镜导航与版本

第四步底部只显示视频分镜进度，前两步的提示词准备、思考和审计计时保留在相应页面。导航按实际分镜数显示 1～N：已有视频显示 √，正在生成的镜头显示转圈，未生成的镜头没有角标。点击编号只滚动结果区，不中断后台任务。

每个镜头顶部显示“共 N 版”和当前所选版本，并提供“重新生成此镜头”。成功保存才新增版本并自动选中新版；失败或停止保留旧版本，生成中仍能切换已有版本观看。版本选择随项目保存，“在文件夹中查看”定位当前选中版本。

旧项目已有的视频自动作为第 1 版。以后重新生成使用独立文件，不覆盖历史成片；清空分镜后仍能在第四步查看和切换已保存版本，重新生成前需要准备分镜。清空视频步骤则须二次确认，移除本步骤所有版本关联，磁盘文件仍保留。

## 上传本地 Skill

分镜大纲或分镜页面上传“分镜 Skill”，视觉素材页面上传“资产 Skill”。点击“复用历史 Skill”可选择以前上传或其他本机项目保存的同类规范，预览全文后应用到当前项目；同名不同内容会分别保留。移除当前 Skill 或删除来源项目不会删除历史，应用仅影响下次生成。文档可指定时长、镜数、画风、模板和素材要求；支持 TXT、MD、DOCX、文字型 PDF，单文件最多 10 MiB、正文最多 200,000 字符，超限会提示，扫描 PDF 需先识别文字。

- 分镜 Skill 替换内置创作默认要求，生成、独立审核和一次回炉使用同一份文档；应用必需的数据结构和素材身份仍会校验。
- 资产 Skill 作用于素材提示词和下一次实际 GPT 生图。已有分镜后再上传，也可直接用于下一次生图。
- Skill 正文随项目保存和 JSON 导入导出。替换仅影响后续请求，历史成果保留当次依据，已有图文和视频不会自动重做。

未上传分镜 Skill 时使用完整的内置 v2.1，原文保存在 `electron/skills/storyboard-v2.1.txt`。生成后执行本地校验和独立审核，失败最多回炉 **一次**；再次审计失败但结构可用且没有真实剧情阻塞时，保留“审计未通过（已忽略）”警告并继续。截断、结构缺失、没有正式提示词或真实缺少剧情材料时仍暂停，并保留此前成果。内置规则执行 60 项审计，用户 Skill 按上传文档的实际条款审核。

分镜正文与审计附件分开展示，复制正文不混入审计说明。审计针对文本与计划，不能代替成片和配音的实际检查。两种生成方式使用相同的 Skill、独立审计及一次回炉规则。应用不设置固定的 24,000 tokens 输出上限，模型与服务端自身的限制仍有效；DeepSeek 单次请求保留 5 分钟总超时，GPT 分镜生成不再设置总时长上限，等待任务完成或用户主动停止。

## 一键跑完全流程

打开左侧 **“一键跑完全流程”**，再点击 **“一键生成到视频”**：从第一步依次生成大纲、分镜、资产提示词，补齐参考图，再批量生成并保存全部镜头视频。开关默认关闭，按项目保存。

- 开始前配置所选分镜生成方式、可用的 GPT 订阅生图和 Seedance；两个阶段的 Skill、分镜模型与思考强度使用本次启动锁定的设置。
- 自动模式按视频接口要求生成 **4–15 秒整数分块**，不会静默拉长短块或截断长块。逐步创作仍可保留内置规范允许的 1–3 秒自然短块，但提交视频前需合理重分块。
- 自动视频始终使用批量方式，全局“逐镜确认”设置保持原值；每镜保存独立 MP4。
- 可停止后续生成；遇到真实材料阻塞、生图失败或视频失败时暂停，保留已完成成果。真人素材需在方舟完成认证并绑定 Asset ID 后继续剩余任务；重启后不会自动重复提交。

## 生成中浏览与阶段重试

同一项目生成时，可点击四个步骤查看和复制已有结果。只有实际运行的步骤显示转圈和“生成中”，提示条提供“返回生成页面”和“停止当前任务”。后台刷新保留阅读位置，用户主动切换后不会被阶段完成或自动接力强制切回。原文、提示词及素材修改在运行期间锁定；切换或新建项目只改变查看页面，当前任务继续，结果保存回原项目；只有显式停止或删除运行项目会取消任务。一次运行一个后台任务，其他项目可自由查看，启动新任务前需等待当前任务完成或显式停止。

阶段按钮的作用始终明确，不受全流程开关影响：

- **重新生成参考图**：按当前素材提示词追加图片版本，保留分析、分镜、原图和已有视频。
- **重新生成全部视频**：仅重做视频。
- **重新生成当前大纲或分镜**：前两步共用的生成入口。

全流程只从左侧“一键生成到视频”主动启动。关闭全流程后，第三步左侧按钮仅补齐缺图，第四步入口仅生成视频。

生成方式、模型或思考强度暂不可修改时，点击或用键盘激活对应选项会弹出提示，说明正在生成、检测或尚未连接。空闲时检测 GPT 不会阻止切回 DeepSeek，后台检测返回也不会替换未变化的下拉框。

**“清空当前步骤”** 只处理当前步骤，并先弹窗确认；可以取消，也可以先导出项目备份。清空分析或分镜只移除对应文本，清空视觉素材只移除图片关联与生成状态、保留素材清单及生图提示词，清空视频只移除视频关联与状态。其他步骤、原文、Skill、模型设置及磁盘文件保留。分镜清空后仍可在第四步播放既有视频；生成期间点击清空只提示先停止，不会直接中断或删除结果。

## 本机数据与网页模式

图片和视频保存在 Windows“文档/StoryForge/项目标题/项目编号”下，按视觉素材、视频片段等目录分类。JSON 项目包用于备份和迁移项目文本、Skill 与关联信息；本地媒体文件需另行备份。各电脑的数据独立保存，当前没有账号登录、云端数据库或自动跨电脑同步。

完整生成能力面向 Electron 桌面版。`npm run dev` 或 Vercel / Netlify 静态部署可用于网页界面预览和本地文字项目管理；纯网页没有桌面通信桥，不能连接本机 Codex，也不提供完整的模型调用、原生文档解析、本机密钥加密和媒体落盘流程。将前端发布到公网不会自动获得这些桌面能力。

## 开发与打包

源码开发环境需要 Node.js 22.13+（或 24+）和 npm，依赖版本以 `package-lock.json` 为准。

```bash
npm ci
npm run dev          # 网页界面开发
npm run desktop      # 构建并运行桌面版
npm run desktop:pack # 生成 Windows 安装包
npm test             # 运行离线测试
```

打包输出：`release-v1.1.1/XStudio-Setup-1.1.1-x64.exe`。关键架构、生成边界和维护要求见 [源码交接说明](HANDOFF.zh-CN.md)。
