# XStudio 1.1.0

- 第一步改为“分镜大纲”，按“生成块 / 预计时长 / 场景 / 剧情内容与镜头重点”输出表格，逐块对应审计后的最终分镜。
- GPT 订阅和 DeepSeek 均生成逐块大纲；支持旧项目显示、复制表格及项目导出。
- 分镜 Skill 和资产 Skill 支持历史复用，可预览以前的同类规范并应用到当前项目，同名不同内容分别保存。
- 软件统一使用 XStudio 名称和透明背景黑色图标，沿用已有项目与模型设置。
- H3 视频页面随当前服务显示正确名称；修复鼠标拖选 ComfyUI 地址时误关闭设置弹窗的问题。

下载 `XStudio-Setup-1.1.0-x64.exe`，关闭旧版后安装更新。源码见 `XStudio-1.1.0-source.zip`，校验值见 `SHA256SUMS.txt`。

验证：415 项离线测试与生产构建通过；安装包内的应用名称、版本、八个图标尺寸及文档导入依赖经过校验。未执行真实模型全流程或安装程序验收。
