# XStudio 1.1.1

- 普通模式按步骤生成：第一步仅生成分镜大纲，确认后再生成分镜脚本，确认分镜后再生成资产提示词。每一步完成后停留原页，等待用户操作。
- 只有打开“一键跑完全流程”并主动启动后，才连续生成大纲、分镜、资产提示词、参考图和视频。
- 切换或新建项目只改变查看内容，正在执行的任务继续，结果保存回原项目。可返回运行项目查看进度；明确停止或删除运行项目才取消任务。
- 修复跨项目清空、真人素材认证恢复、H3 设置与引用归属等边界问题。一次只运行一个后台任务，可自由查看其他项目。
- 新分镜保留历史成片，但会等待按当前分镜重新生成，避免旧成功状态让全流程跳过视频。

关闭旧版后安装 `XStudio-Setup-1.1.1-x64.exe`。源码和校验值见同页附件。

验证：461 项离线测试通过，覆盖两种文本模型的分步接口、逐步确认、全流程及跨项目后台任务；安装包版本、名称、八个图标尺寸和文档导入依赖经过校验。未执行收费模型全流程或安装程序验收。
